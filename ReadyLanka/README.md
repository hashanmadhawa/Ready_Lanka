# ReadyLanka — Final Commit

This is the completed ReadyLanka offline emergency-preparedness app.

## Features completed

The final app includes offline emergency guides, search, Preparation/During/After advice, an emergency-kit checklist, saved guide favorites, emergency contacts, tap-to-call behavior, delete confirmation, and AsyncStorage persistence for favorites, checklist progress and contacts.

## Run

```bash
npm install
npx expo-doctor
npx expo start
```

For a web preview:

```bash
npx expo start --web
```
